Results

Free-viewpoint 4D from a single video.

Method

Nine synchronized views, then 4D.

01

Multi-view as multi-shot

Each target camera is a shot in one sequence, so attention ties the views together.

02

Geometry-aware conditioning

Depth-warped input, visibility masks and Plücker rays guide every view.

03

Cross-view consistency loss

A pixel-level loss keeps the generated views in agreement.

04

4D Gaussian lifting

FreeTimeGS turns the nine views into real-time 4D Gaussians.
